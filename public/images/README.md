# Candisari Hotel & Resto - Images

Place your hotel images in this directory with the following names:

## Required Images

### Hero
- `hero-bg.jpg` - Main hero background image (hotel exterior with garden/palm trees)

### Rooms
- `room-standard.jpg` - Standard room photo
- `room-deluxe.jpg` - Deluxe room photo
- `room-family.jpg` - Family room photo

### Gallery (for masonry grid)
- `gallery-1.jpg` - Hotel exterior
- `gallery-2.jpg` - Garden/hotel grounds
- `gallery-3.jpg` - Standard room
- `gallery-4.jpg` - Swimming pool
- `gallery-5.jpg` - Restaurant/food
- `gallery-6.jpg` - Hotel lobby
- `gallery-7.jpg` - Garden view
- `gallery-8.jpg` - Breakfast
- `gallery-9.jpg` - Hotel facilities

### CTA Background
- `cta-bg.jpg` - Booking CTA background (hotel exterior/garden)

### Social Media
- `og-image.jpg` - Open Graph image (1200x630px)

### Favicon
- `favicon.ico` - Hotel favicon

## Tips

- Use high-quality images (min 1200px wide for hero/backgrounds)
- Compress images for web (use tools like TinyPNG)
- Use JPG format for photos
- Recommended hero image: 1920x1080px
- Recommended OG image: 1200x630px
